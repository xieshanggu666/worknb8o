# 无人机电力巡检任务规划系统

基于 **FastAPI + SQLite** 后端与 **Vue 3（本地运行时，离线可用）** 前端的输电线路无人机巡检管理平台。

## 功能模块

- **线路台账**：输电线路、杆塔（巡检对象）的档案与坐标、里程、风险标识（正常/可疑/重点）。
- **机队与电池**：无人机（机型、载荷、状态）与电池包（续航、电量、循环次数）管理。
- **任务规划引擎**：
  - **航线规划**：沿线路杆塔序列自动生成航线点，可传障碍（禁飞/施工杆塔）自动跳过并重排。
  - **电量核算**：根据航线里程 + 返航距离 + 安全余量（20%）核算所需电比例，判定可飞性。
  - **机队调度**：贪心选择"电能余量最小但足够"的无人机 + 电池组合，把高电量电池留给更远任务。
  - **任务闭环**：执行任务时扣除电池电量、记录飞行合规、沿航线生成巡检影像、按缺陷生成工单。
- **缺陷工单**：按缺陷等级（轻微/较大/重大）分级，闭环状态流为
  **待处理 →（派单·处理人）→ 处理中 →（提交结果）→ 待复核 →（复核通过）→ 已关闭**，
  复核可**退回**（记录原因、退回次数）后重新派单；按等级 SLA（重大 24h / 较大 72h / 轻微 168h）判定**超时**，
  并实时回写杆塔风险标识与任务、线路缺陷统计。
- **飞行合规记录**：每次起飞记录航次、电量起止、天气与放行来源。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3.10+ / FastAPI / SQLAlchemy 2.0 / SQLite |
| 前端 | Vue 3 单页应用（vue.global.prod.js 本地运行时，无需构建） |
| 测试 | pytest（规划引擎 + 工单闭环，19 例） |

## 快速开始

```bash
pip install -r requirements.txt   # 安装 Python 依赖（仅首次）
npm run dev                       # 一键启动
```

一条命令完成：自动初始化数据库（幂等）、自动检测可用端口（8000 被占用时自动换端口）、自动打开浏览器。

也可手动指定端口：`PORT=9000 npm run dev`。

## 演示数据

预置 2 条线路（110kV 环城一线 10 塔、220kV 滨江双回 8 塔）、3 架无人机、4 块电池。可直接进入「巡检任务」选择线路+杆塔区间 → 自动规划航线 → 分配机队 → 执行巡检 → 生成影像与缺陷工单。

## 目录结构

```
drone_inspection/
├── app/
│   ├── main.py            # 应用入口
│   ├── core/              # 配置 / 数据库
│   ├── models/            # 7 张表（线路/杆塔/无人机/电池/任务/影像/工单/飞行记录）
│   ├── schemas/           # Pydantic 校验模型
│   ├── services/engine.py # 规划引擎（航线/电量/机队调度/闭环）
│   └── api/router.py      # REST 接口
├── static/                # Vue 单页应用
├── scripts/init_db.py     # 数据库初始化与演示数据
├── tests/                 # 规划引擎单元测试
└── data/                  # SQLite 数据库
```

```bash
pytest tests -q
```
